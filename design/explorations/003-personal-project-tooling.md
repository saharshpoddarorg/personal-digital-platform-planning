# Personal project tooling direction

Recorded: 2026-10-31. Status: provisional direction agreed in conversation; no final tool adoption or installation required.

## Needs clarified by the user

- Mostly personal development with agents acting on the user's behalf and occasional collaboration with a couple of friends; no enterprise team requirement.
- Familiar with Jira's epics, stories and subtasks; wants granular feature breakdown and an ideas backlog, not an assumed enterprise reporting system.
- Familiar with Confluence's hierarchy and formatting. Desired macros primarily mean indexes/table of contents, child/related pages, links, code blocks, tables and Jira links. Live issue status/report requirements have not been established.
- Prefer free versions; consider paid options for meaningful demonstrated benefit.

## Provisional direction

GitHub Free is the initial direction for code, PRs and development backlog. Obsidian Free is the leading candidate for the Git-backed personal vault, not a finalized tool choice. Jira/Confluence remain alternatives if a concrete gap justifies them. No subscription, installation, migration or mandatory tool evaluation is authorized by this direction.

The assistant proposed a disposable trial and prepared local sample files after user agreement. The user subsequently questioned its necessity; the assistant agreed it could be skipped, and the user accepted the provisional direction without requiring the trial. The sample was not a real vault or GitHub repository, and no issues/board were created. Do not make completing that trial a prerequisite or claim its rendering/mobile/sync behavior was verified.

A proposed ownership split is project issues in the tracker, project-specific decisions in their authoritative documentation, and reusable concepts in the personal vault, linked rather than duplicated. This split is a recommendation, not a finalized migration or repository policy. Existing planning documents remain authoritative here.

## Evaluation findings and limits

Official documentation consulted on 2026-10-31 supports GitHub parent/sub-issues and Project hierarchy, and Obsidian Outline, Backlinks, Bases views and formatted tables/code. These support the candidate direction but do not prove an identical Jira/Confluence experience. Folder trees, parent-page relations and recursive embedded child lists remain distinct. Backlinks identify references, not every semantically related note. Ordinary issue links do not imply live status integration.

Dynamic Obsidian views need a readable fallback for portability under U11; automatic fallback refresh was not implemented or selected. Mobile Git/sync, external-tool reconciliation and specific free-plan restrictions remain subjects for later evaluation. Recheck pricing and capability availability before purchase or configuration.
